# `head` - Display the Beginning of a File

## 1. What is `head`?

The `head` command displays the first part of a file.

By default, it displays the first 10 lines.

---

## 2. Basic Syntax

```bash
head file.txt
```

---

## 3. Display a Specific Number of Lines

```bash
head -n 5 file.txt
```

This displays the first 5 lines.

---

## 4. Use with Command Output

Example:

```bash
ps aux | head
```

---

## Quick Reference

```bash
head file.txt
head -n 5 file.txt
ps aux | head
```

---

## Summary

`head` displays the beginning of a file or command output.

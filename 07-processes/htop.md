# `htop` - Interactive Process Viewer

## 1. What is `htop`?

`htop` is an interactive process monitoring tool for Linux.

It provides a more user-friendly interface than `top`.

It can display:

* CPU usage
* Memory usage
* Running processes
* Process trees

---

## 2. Run `htop`

```bash
htop
```

---

## 3. Install `htop`

On Ubuntu or Debian:

```bash
sudo apt install htop
```

On Fedora:

```bash
sudo dnf install htop
```

---

## 4. Useful Features

`htop` allows you to:

* Scroll through processes.
* Search for processes.
* Sort processes.
* Kill processes.
* View process trees.

---

## 5. Common Keyboard Shortcuts

| Key   | Action       |
| ----- | ------------ |
| `F3`  | Search       |
| `F4`  | Filter       |
| `F5`  | Tree view    |
| `F6`  | Sort         |
| `F9`  | Kill process |
| `F10` | Quit         |

---

## 6. Why Use `htop`?

Compared with `top`, `htop` is easier to navigate and provides an interactive interface.

---

## 7. Related Commands

| Command | Purpose                     |
| ------- | --------------------------- |
| `htop`  | Interactive process monitor |
| `top`   | Process monitor             |
| `ps`    | Process information         |
| `kill`  | Stop processes              |

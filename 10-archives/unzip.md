# `unzip` - Extract ZIP Archives

## 1. What is `unzip`?

The `unzip` command extracts files from ZIP archives.

---

## 2. Basic Syntax

```bash
unzip archive.zip
```

Example:

```bash
unzip project.zip
```

---

## 3. Extract to a Specific Directory

Use:

```bash
unzip archive.zip -d destination/
```

Example:

```bash
unzip project.zip -d /home/deviprasad/projects/
```

---

## 4. List ZIP Contents

Use:

```bash
unzip -l archive.zip
```

This displays the contents without extracting the files.

---

## 5. Test a ZIP Archive

Use:

```bash
unzip -t archive.zip
```

This tests the archive for common integrity problems.

---

## Quick Reference

```bash
unzip archive.zip
unzip archive.zip -d destination/
unzip -l archive.zip
unzip -t archive.zip
```

---

## Summary

`unzip` extracts and manages ZIP archive files.

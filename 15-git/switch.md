# `git switch` - Switch Git Branches

## 1. What is `git switch`?

`git switch` is a modern Git command designed specifically for changing branches.

---

## 2. Switch Branch

```bash
git switch main
```

---

## 3. Create and Switch to a Branch

```bash
git switch -c feature-login
```

The `-c` option creates the branch and switches to it.

---

## 4. Switch Back to the Previous Branch

```bash
git switch -
```

---

## Quick Reference

```bash
git switch main
git switch feature-name
git switch -c feature-name
git switch -
```

---

## Summary

`git switch` provides a clear and focused way to work with Git branches.
